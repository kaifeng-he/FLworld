# FL小世界

**FL小世界** 是一款只为两个人准备的 Android 私密空间 App。它把异地陪伴中的聊天、想说的话、重要日期、照片和共同回忆放在同一个小世界里，让两人可以在各自的手机上共享更新，也让名为 **小暖** 的 AI 陪伴者逐渐理解两个人的故事。

目前项目面向 Android 手机使用，后端部署在腾讯云 CloudBase，适合国内网络直接访问。

> 当前内容仅适用于作者。如自用，则需修改其中部分内容，比如 AI 提示词、用户称呼等等。

## 主要功能

- **小暖聊天**：两人共享聊天记录，支持流式回复、自动生成会话标题、历史会话管理和可选择的聊天风格。
- **我想对你说**：像留信一样给对方留下想说的话，对方收到新留言时会显示未读红点与数量。
- **重要日子**：共同创建、修改和删除纪念日或目标日，首页展示近期日期卡片及距当天数。
- **共享相册**：上传照片或视频，提供轻量预览、下载状态提示、重命名与删除功能。
- **相隔距离**：App 获取粗略位置后计算两人的距离；点击距离卡片可以查看双方所在省市与更新时间。
- **共同回忆**：双方可以撰写和维护回忆文档；小暖会从聊天或共同资料中提炼长期记忆，且记忆内容可编辑、删除。
- **个性化界面**：恋爱主题背景、可调整的背景清晰度、页面切换动画和针对移动端设计的功能入口。

## 项目结构

- `android/`：Kotlin 原生 Android 客户端，界面使用 Jetpack Compose。
- `server/`：腾讯云 CloudBase HTTP 云函数后端，负责身份认证、数据同步、云存储和 DeepSeek API 调用。
- `开发记录/`：各版本需求记录及后续规划。

后端使用的服务：

- **云数据库**：保存聊天、留言、日历、位置、相册元数据、会话认证和双方可维护的回忆。
- **云存储**：保存共享相册中的照片和视频文件。
- **DeepSeek API**：由云函数使用配置的 API Key 提供小暖回复、标题生成和长期记忆提炼。

## 运行与部署

### 后端运行

```bash
cd server
npm install
npm run dev
```

线上部署到腾讯云 CloudBase HTTP 云函数，使用 CloudBase 默认 HTTPS 域名即可在国内访问。

### Android 运行

将 CloudBase 后端地址配置到 `android/gradle.properties`：

```properties
FLWORLD_API_BASE_URL=https://你的默认域名
```

然后用 Android Studio 打开 `android/` 目录，等待 Gradle 同步后运行到手机或模拟器。

从零部署 CloudBase 后端、配置 Android 和日常更新的完整步骤见：

- [重新部署和运行教程](./重新部署和运行教程.md)

## 默认账号

后端默认支持两个固定用户：

- `hkf`：App 内显示为“锋宝”
- `cl`：App 内显示为“璐宝”

线上登录口令通过 CloudBase 云函数环境变量配置；登录 token 由后端按设备签发，同一身份新登录会替换旧设备。
